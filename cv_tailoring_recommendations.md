## Section 3: Gap Analysis

### 3.1 The Five Most Damaging Gaps (ATS Killers)

**Gap 1: Vector Databases — Missing from all 3 CVs**
Vector databases appear in 16 of 25 job listings and are the most frequently cited missing skill. Every serious AI/ML engineering role now expects hands-on vector DB experience. The CVs never mention Pinecone, FAISS, Chroma, Weaviate, Milvus, pgvector, or Azure AI Search. This alone likely causes ATS rejection on the majority of listings. This must be added to every CV immediately.

**Gap 2: FastAPI — Missing from all 3 CVs**
FastAPI appears in 13 listings (Precision Medicine Group, RandomTrees, Genios AI, Metova, ChatGPT Jobs junior role, Azumo, and others) as the expected Python web framework for AI/ML APIs. The CVs only list Flask and Django. FastAPI has become the production standard for ML services. Adding it is a simple, high-impact fix.

**Gap 3: SQL / PostgreSQL — Missing from all 3 CVs**
SQL is required in 12 listings (Vendelux, Cherre, Genios AI, Junior AI/ML Engineer, Pasito, RandomTrees, and others). The CVs reference Firebase and SQLite as database technologies but never write the word "SQL." This is a significant ATS gap, especially for roles that involve integrating LLMs with enterprise data.

**Gap 4: Model Monitoring, Observability, and Evaluation — Missing from all 3 CVs**
Referenced in 11 listings with specific tools: MLflow (Precision Medicine Group, Azumo), LangFuse (Cherre, Pasito), LangSmith (Pasito), OpenTelemetry (Cherre), and custom evaluation pipelines (NISC, Genios AI, ClearlyAgile). The CVs describe "validation pipelines" but never use the industry vocabulary: LLMOps, model monitoring, hallucination detection, offline evals, regression detection, or observability.

**Gap 5: Commercial LLM API Experience — Missing from all 3 CVs**
9 listings explicitly require experience with OpenAI GPT-4, Anthropic Claude, or Google Gemini APIs (ClearlyAgile, Metova, Influur, Genios AI, Pasito, Nxt Level Finance, RandomTrees, Saransh Inc, Software Technology Inc). The CVs exclusively show Hugging Face and Ollama, which signals only local/open-source model experience. Employers targeting production LLM products assume API-based workflows. If the candidate has used these APIs, this must be added.

### 3.2 Skills in CVs That Are Undervalued and Should Be Elevated

**MCP and A2A Protocol Expertise**
This is the candidate's single most powerful differentiator. The Metova listing explicitly requires "Practical knowledge of MCP and A2A protocols" as a mandatory skill. The Saransh Inc listing makes A2A and MCP mandatory. Several other listings show strong interest. Yet in the CVs, MCP and A2A are buried inside skill list sentences. They deserve standalone bullet points with specific project outcomes, linked directly to the published Medium article. This is rare expertise in the market right now.

**Published Technical Articles on Medium**
Multiple employers explicitly value open-source contribution and published writing (NISC, Azumo, Cherre). The CVs mention articles but bury them. The article titles should appear prominently with links, framed as thought leadership, not just mentioned in passing.

**Quantified Production Metrics**
The Soft Dev and SoftwareDevCV include three strong metrics: 40% reduction in manual processing time, 99.9% uptime SLA, and 70% of production workloads. These are highly convincing to employers. However they are buried mid-paragraph and not formatted as standalone achievements. They should be in a dedicated highlights section at the top of the CV, visible within the first glance.

**Agentic RAG and Hybrid RAG**
Very few candidates have hands-on Hybrid RAG or Agentic RAG experience. Multiple listings (NISC, Cherre, Egen, Pasito, Genios AI) use exactly these terms. The CVs mention them in the profile summary but not as bullet points showing what was actually built and what outcome it produced.

**GitHub and Open-Source Work**
Several listings require GitHub evidence (Junior AI/ML Engineer role requires a GitHub link with an agent project; Cherre explicitly says "Show us your AI skills in your application"). The GitHub link exists on the CV but is not being leveraged as a portfolio point.
